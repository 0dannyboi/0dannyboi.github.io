Lab Notebook Entry Builder

Low-friction research notes: motivation, setup, results, questions, and paths.

Entry Fields

Pre-Lab / Planning

Add as many paths as needed: simulation code, analysis scripts, data folders, plots, configs, notes, etc.

This runs entirely in your browser. No server required.

Markdown Preview


    


    

      
How to use

      

        Fill out the fields, generate markdown, then save the entry into your GitHub repo under something like
        lab_notes/2026-05-01_tfim_binder_scan.md.
      

      

        For plots, save thumbnails in lab_notes/assets/ and add a path entry such as
        assets/2026-05-01_binder_scan.png. You can also manually add a Markdown image link:
      

      
![Binder scan](assets/2026-05-01_binder_scan.png)
